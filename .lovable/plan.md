
## Προσθήκη εικόνων στις κάρτες Κατηγοριών (Academy)

Θα προσθέσουμε μια banner εικόνα στο πάνω μέρος κάθε κάρτας κατηγορίας, ώστε να είναι πιο οπτικά ελκυστικές.

### Τι αλλάζει

- Κάθε κάρτα κατηγορίας (Διαφήμιση, Ιστοσελίδες, AI) αποκτά μια φωτογραφία-banner στο πάνω μέρος
- Η φωτογραφία θα έχει ένα ελαφρύ gradient overlay για να διατηρηθεί η αναγνωσιμότητα
- Το icon μετακινείται πάνω στη φωτογραφία (κάτω αριστερά, σε μικρό pill) για καθαρότερο layout
- Διατηρείται το ίδιο hover effect και το υπόλοιπο περιεχόμενο κάτω από την εικόνα

### Τεχνικές λεπτομέρειες

**Αρχείο:** `src/pages/Academy.tsx`

1. Προσθήκη πεδίου `image` στο array `tracks` με URL εικόνας για κάθε κατηγορία (θα χρησιμοποιηθούν Unsplash εικόνες μέσω URL)
2. Αναδιαμόρφωση κάθε κάρτας:
   - Πάνω μέρος: `div` με `aspect-ratio ~16/9`, `overflow-hidden`, `rounded-t-xl` για την εικόνα
   - Gradient overlay (`from-transparent to-card/80`) πάνω στην εικόνα
   - Icon badge ημι-διάφανο στο κάτω αριστερά μέρος της εικόνας
   - Κάτω μέρος: τίτλος, περιγραφή, bullets (ίδια δομή)
3. Η κάρτα γίνεται `overflow-hidden` και `p-0` (padding μόνο στο content area)

Οι εικόνες θα είναι σχετικές με κάθε θέμα:
- Διαφήμιση: marketing/social media imagery
- Ιστοσελίδες: web design/code imagery  
- AI: technology/automation imagery
